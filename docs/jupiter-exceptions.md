# Jupiter style exceptions

The table felt, slot outlines, and card faces are a content palette under
section 3.4. The green felt is the same in either Windows appearance because
it provides the background for the cream-colored artwork. In a Windows
contrast theme the table and empty slots use Jupiter system contrast resources.
Card images retain their artwork and expose the rank and suit to automation.
The custom app icon uses the Design 1 ace and back.
